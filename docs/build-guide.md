# Гайд для чайника: собрать safegamingOS и запустить в виртуалке

Тебе не нужен Arch Linux и не нужна флешка — всё собирается в облаке GitHub,
а тестировать будем в виртуалке на твоей Windows.

---

## Шаг 0. Что нужно

- Аккаунт на GitHub (у тебя уже есть — репозиторий подключён).
- **VirtualBox** — бесплатно: https://www.virtualbox.org/ → Download → Windows.
  Установи как обычную программу (все настройки по умолчанию, «Далее» → «Далее»).
- Ничего больше ставить не нужно.

---

## Шаг 1. Получить ISO (сборка в облаке)

1. **Запушь изменения в репозиторий.** В панели Changes (Freebuff) нажми
   Save/Commit → Push, чтобы на GitHub улетел файл `.github/workflows/build-iso.yml`.
2. Открой браузер → `https://github.com/met4444m-collab/safegamingos`.
3. Вкладка **Actions** (вверху, рядом с Code).
4. Слева список workflows — нажми **Build ISO**.
5. Справа кнопка **Run workflow** (синяя). Ничего не меняй, нажми её ещё раз.
6. Запустится сборка. Она идёт **10–20 минут** — видно жёлтый кружок.
7. Когда кружок станет **зелёной галочкой** — внизу страницы появится секция
   **Artifacts** (белая коробка с облаком) → нажми **safegamingos-iso**.
8. Скачается ZIP-файл. Распакуй его (правой кнопкой → «Извлечь всё») —
   внутри будет **`safegamingos-0.9.0-x86_64.iso`**. Это и есть наша ОС.

> Если сборка упала (красный крест) — нажми на красный шаг, скопируй текст
> ошибки и пришли его мне. Разберу.

---

## Шаг 2. Создать виртуалку в VirtualBox

1. Открой VirtualBox → кнопка **Создать** (New).
2. Имя: `safegamingOS` (любое). Тип: **Linux**, Версия: **Arch Linux (64-bit)**. → Далее.
3. Память: поставь **4096 MB** (можно 2048, если RAM мало). → Далее.
4. Жёсткий диск: **Создать новый виртуальный диск** → Далее.
   - Тип: **VDI** → Далее.
   - «Динамический виртуальный диск» → Далее.
   - Размер: **30 GB** (минимум 20). → Создать.
5. Выдели виртуалку в списке слева → кнопка **Настроить** (Settings).
6. Вкладка **Носители** (Storage):
   - Под «Контроллер: IDE» есть значок оптического диска «Пусто» → нажми на
     синий диск с плюсиком (рядом) → **Выбрать образ диска**.
   - Укажи путь к `safegamingos-0.9.0-x86_64.iso` из Шага 1. → OK.
7. Нажми **Запустить** (зелёная стрелка).

> Чёрный экран при загрузке? Зайди в Настройки → Система → Материнская плата →
> включи галочку **Включить EFI** → OK → перезапусти. Если и так не помогло —
> пиши мне.

## Шаг 3. Внутри live-системы

1. Подожди загрузку — будет экран с прыгающим логотипом **SAFEGAMINGOS**.
2. Увидишь рабочий стол KDE. Логин: **`live`** / пароль: **`live`**.
3. На рабочем столе есть иконка **«Установить safegamingOS»** — двойной клик.
   (Или: меню → Konsole → ввести `sudo sg-install`.)

## Шаг 4. Установка на диск (по шагам внутри инсталлятора)

Отвечай на вопросы инсталлятора (стрелки ←↑↓→ + Enter, «Да/Нет» = Enter):

1. **Диск** — выбери `/dev/sda` (в виртуалке диск один, он и нужен).
   Нажми «Ок». Инсталлятор сам разметит, отформатирует и поставит систему.
2. **Хостнейм** — например `safegamingos`. Enter.
3. **Имя пользователя** — например `gamer`.
4. **Пароль пользователя** — придумай и введи дважды (вводится «вслепую», без точек).
5. **Пароль root** — придумай и введи дважды.
6. **Размер подкачки (swap)** — оставь **16G** (это файл подкачки, по твоему ТЗ).
7. **Ставить Wine/Steam/Lutris?** — `Нет` для первой установки (быстрее),
   `Да` — если хочешь сразу Windows-игры. Multilib включится сам.

Дальше идёт установка: **10–30 минут** (зависит от интернета). Не выключай VM.
В конце инсталлятор скажет «Готово» и предложит перезагрузиться.

## Шаг 5. Перезагрузка в установленную ОС

1. Когда инсталлятор завершится — **выключи виртуалку**.
2. Настройки → Носители → отключи ISO (правый клик по диску → «Отключить
   образ»), чтобы VM не грузилась с live-диска заново. → OK.
3. Запусти виртуалку. Загрузится уже **установленная safegamingOS**.
4. Войди под своим пользователем и паролем.

## Шаг 6. Всё уже настроено — вводить ничего не надо 🎉

После первого входа рабочий стол уже готов:

- 🌐 **Браузер (комната)** — Firefox в изолированной комнате (4G RAM, 2 ядра)
- 🎮 **Игры (комната)** — PrismLauncher в игровой комнате (8G RAM, 4 ядра)
- 🎥 **Стрим (комната)** — OBS в игровой комнате
- 🛡 **SafeGuard** — графический центр безопасности (комнаты, антивирус, сеть, журнал)
- Обои safegamingOS и 16 ГБ swap уже стоят, антивирус ClamAV сам обновляет базы при старте.

По желанию (в Konsole, `Ctrl+Alt+T`):

```bash
sudo sg-av live        # сколько RAM/CPU едят комнаты прямо сейчас
sudo sg-av scan ~/Downloads/файл   # проверить скачанный файл
```

## На реальное железо (позже, по желанию)

- Скачай ISO, вставь флешку (≥4 ГБ) → открой **Rufus** (https://rufus.ie) →
  выбери ISO → режим **DD** → «Старт». Готово, загружайся с флешки.
- Осторожно: на реальном железе установка **затрёт выбранный диск целиком**.
  Делай это только на машине, где не жалко данных.

## Проблемы и решения

| Проблема | Решение |
|----------|---------|
| Сборка в Actions упала | Пришли мне текст из красного шага |
| Чёрный экран при загрузке VM | Включи EFI в настройках VM (см. Шаг 2) или увеличь RAM до 4096 |
| Не видно диск в инсталляторе | В настройках VM должен быть создан виртуальный диск |
| Live-логин не работает | Имя `live`, пароль `live` (ввод вслепую — просто Enter дважды) |
| Нет звука в VM | Это норма для виртуалки: Настройки VM → Аудио → включить |
| Установка падает на Wine/Steam | Ставь без них (Шаг 4, пункт 7 = Нет), потом доставишь через pacman |
| Не помогло ничего | Напиши мне, что происходит — разберём по логам |
