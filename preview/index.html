Что это за проект

safegamingOS — кастомная ОС на базе Arch Linux, собираемая в загрузочный ISO через mkarchiso. Вместо виртуальных машин (KVM/QEMU, которые «жрут» ОЗУ) приложения запускаются в изолированных комнатах: лёгкая, но жёсткая изоляция на уровне ОС, чтобы даже на слабом ПК хватало ресурсов для игр, OBS и стримов.

Возможности

Изоляция комнат без VM

Комнаты на уровне ОС: firejail (namespace + seccomp + no_new_privs + caps.drop), per-room UID (ядро разделяет /proc, /dev/shm и файлы), AppArmor-профиль поверх. Вирус из комнаты физически не выходит за её границы.

Антивирус с источником загрузки

SafeGuard запоминает, с какой ссылки скачан файл в браузере (автоматически). При обнаружении вируса комната предлагает: удалить вирус, карантин или удалить комнату — и блокирует источник системно. Пользователь может разблокировать ссылку вручную.

Игровые комнаты

У обычной комнаты нет доступа к чужому экрану, клавиатуре и звуку. В игровой комнате (например, для OBS) можно явно разрешить захват экрана, звука и ввода из других комнат.

Windows-приложения

Minecraft, Roblox, OBS Studio. В инсталляторе выбор: Wine или Proton (для игр). Swapfile до 16 ГБ для требовательных игр и ИИ.

Рабочий стол

KDE Plasma 6 (Wayland по умолчанию — экран и ввод изолированы порталами) с нестандартным, узнаваемым оформлением safegamingOS.

Железо

Автоподбор лучших драйверов (Intel GPU на ноутбуках): система сама проверяет и ставит подходящие.

Сборка ISO (у себя, на Arch Linux)

# 1. установить archiso
sudo pacman -S archiso

# 2. собрать (долго, нужен root)
sudo ./build_iso.sh

# 3. записать на флешку / в VM
sudo dd bs=4M if=out/safegamingos-0.9.7-x86_64.iso of=/dev/sdX status=progress oflag=sync

Сборка выполняется на вашей Arch-машине (или в Arch-контейнере) — не в браузере. Этот превью-экран просто показывает статус и документацию проекта.
